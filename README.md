# FocusFox 🦊

**FocusFox** is a lightweight and customizable browser start page designed to keep your new tabs clean, fast, and distraction-free.

### Features

* 🔎 Search with **ChatGPT, DuckDuckGo, or Perplexity**
* 🔗 Customizable one-click shortcuts
* 🎯 Clean, distraction-free new tab experience
* ⚡ Fast and lightweight
* 📱 Responsive design

### Firefox Add-on

Install FocusFox from the Firefox Add-ons Marketplace:

**[FocusFox — Firefox Add-on](https://addons.mozilla.org/en-US/firefox/addon/focusfox/)**
